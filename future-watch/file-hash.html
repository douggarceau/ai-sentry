File Hash Verifier

Software publishers list a checksum (a fingerprint) next to their downloads. Compare it with your copy to make sure the file is exactly the one they published.

Runs in your browser. Nothing you enter is sent anywhere.

The file is read on your device and never uploaded.

Or check from your computer's command line

  • Windows (PowerShell): Get-FileHash .\file.exe -Algorithm SHA256
  • Mac: shasum -a 256 file.dmg
  • Linux: sha256sum file.iso

Only trust a checksum shown on the publisher's own website over HTTPS. A checksum next to a download on a third-party site proves nothing.
